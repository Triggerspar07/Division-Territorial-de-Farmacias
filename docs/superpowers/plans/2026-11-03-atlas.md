# Atlas Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Reconstruir la consulta territorial preservando todos los datos y ofreciendo Atlas claro y Territorio nocturno con movimiento accesible.

**Architecture:** Mantener una aplicación estática sin compilación. Separar datos originales, consultas puras, representación de fichas, mapa Leaflet y coordinación de controles. Dependencias y fuentes se sirven localmente.

**Tech Stack:** HTML, CSS, ES modules, Leaflet 1.9.4, Node test runner.

**Spec:** ../specs/2026-11-03-atlas-design.md

## Global Constraints

- Conservar todos los registros y valores originales.
- Funcionar en GitHub Pages con rutas relativas.
- Mantener información de horarios, servicios, estados y procedencia.
- Respetar prefers-reduced-motion; sin bucles decorativos.
- No actualizar sucursales sin el JSON pendiente.

## Review Focus

- Distritos homónimos en distintos departamentos: no mezclar sucursales.
- Booleanos, datos faltantes y teléfonos numéricos: mantener su significado.
- Texto de datos con etiquetas HTML: mostrarlo como texto, no ejecutarlo.
- Coordenadas nulas/no numéricas: no crear puntos falsos.
- Red o almacenamiento no disponible: conservar el directorio utilizable.
